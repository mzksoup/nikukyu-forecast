# にくきゅう天気予報

アスファルト路面の温度を予測し、犬の肉球を守るためのシンプルなWebアプリです。  
Open-Meteoの気象データと位置情報を使って、現在地周辺の路面温度と3日分の予報を表示します。

## 特徴

- 現在地のGPS取得に対応
- GPSが使えない場合はIPベースの位置推定にフォールバック
- 3段階以上の危険度で路面温度を判定
- 今日・明日・明後日の時間別タイムラインとグラフを表示

## 技術構成

- HTML
- JavaScript (ES Modules)
- Tailwind CSS
- Lucide Icons

## 主要ファイル

- `index.html` - 画面本体とアプリ起点
- `src/services/` - 位置情報・天気API取得
- `src/render/` - カードやタイムライン描画
- `src/utils/` - 日時・温度・位置ラベルの計算
- `src/canvas/` - グラフ描画

## 注意

- 位置情報はブラウザの許可が必要です。
- 予測値は参考情報で、実際の路面温度とは差が出る場合があります。
