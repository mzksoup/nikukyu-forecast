# にくきゅう天気予報

アスファルト路面の温度を予測し、犬の肉球を守るためのシンプルなWebアプリです。  
Open-Meteoの気象データと位置情報を使って、現在地周辺の路面温度と3日分の予報を表示します。

## 特徴

- 現在地のGPS取得に対応
- GPSが使えない場合はIPベースの位置推定にフォールバック
- 3段階以上の危険度で路面温度を判定
- 今日・明日・明後日の時間別タイムラインとグラフを表示

## アスファルト路面温度の計算ロジック
路面予測温度(℃) = `気温 ＋ ［ (日射量 × 0.85 × 0.70 － 100) / 総合熱伝達率 ］× (1 － 降水抑制率)`

詳細
- 純放射量：アスファルト日射吸収率 0.85 / 有効表面蓄熱率 0.70
- 対流・放射熱伝達：Jürgesの式 [5.6 + 3.9 × 風速] + 放射伝達係数 [5.0]
- 長波放射冷却：大気への実効放射量として定数 100 W/m² を減算
- 降水抑制：降水量(mm/h) ÷ 20 を0〜1にクランプした値。蒸発潜熱・水膜により
  路面が外気温に近づく効果の簡易近似で、20mm/h以上（激しい雨）でほぼ気温相当になる

## 技術構成

- HTML
- JavaScript (ES Modules)
- Tailwind CSS
- Lucide Icons

## 主要ファイル

- `index.html` - 画面本体(マークアップ)
- `src/main.js` - アプリ起点(位置情報取得・API呼び出し・ドラッグ操作などの制御)
- `src/services/` - 位置情報・天気API取得
- `src/render/` - カードやタイムライン描画
- `src/utils/` - 日時・温度・位置ラベルの計算
- `src/canvas/` - グラフ描画

## テスト

```bash
npm test
```

## 注意

- 位置情報はブラウザの許可が必要です。
- 予測値は参考情報で、実際の路面温度とは差が出る場合があります。
